# Agent Notch — 要件定義書

## 1. プロダクトビジョン

> Mac の notch を AI コーディングエージェントの**統合コマンドセンター**に変える、
> **無料・OSS・多エージェント対応**の macOS ネイティブアプリ。

### 競合との差別化マトリクス

| 要素               |  Claude Island   | AgentNotch | Vibe Island | **Agent Notch (本アプリ)** |
| ------------------ | :--------------: | :--------: | :---------: | :------------------------: |
| OSS                |        ✅        |     ✅     |     ❌      |             ✅             |
| 多エージェント対応 | ❌ (Claude のみ) |  △ (2種)   |  ✅ (6種)   |      ✅ (6種+拡張可)       |
| GUI 権限承認       |        ✅        |     ❌     |     ✅      |             ✅             |
| テレメトリ分析     |        ❌        |  △ (基本)  |     ❌      |         ✅ (詳細)          |
| カスタマイズ性     |        ❌        |     ❌     |     ❌      |   ✅ (テーマ/レイアウト)   |
| プラグイン拡張     |        ❌        |     ❌     |     ❌      |             ✅             |
| 価格               |       無料       |    無料    |   $19.99    |          **無料**          |

## 2. コア差別化戦略

### 2.1 唯一の「OSS × 多エージェント × 高機能」

- Claude Island は OSS だが Claude のみ
- Vibe Island は多エージェント対応だが有料クローズド
- **本アプリが唯一、OSS で多エージェント対応かつ高機能を実現する**

### 2.2 プラグインアーキテクチャ

- 新しい AI エージェントへの対応をコミュニティが拡張可能
- カスタムウィジェット（ポモドーロ、Git状態等）をプラグインで追加
- 競合は全てハードコードされた対応 — 拡張性ゼロ

### 2.3 テレメトリダッシュボード

- セッション別トークン消費/コスト推計のリアルタイム表示
- 日次/週次の利用統計（ローカル保存）
- 競合で深い分析を提供しているアプリは存在しない

### 2.4 演出とカスタマイズ

- TheBoringNotch 級のリッチアニメーション + AI エージェント特化
- テーマエンジン（ダーク/ライト/カスタム）
- notch の展開サイズ・表示項目のユーザー設定

## 4. 機能要件

### 4.1 Notch UI（コア）

#### 4.1.1 コンパクトモード（常時表示）

- notch 両サイドにアクティブセッションのインジケーター表示
- 各エージェントのアイコン + 色 + 状態アニメーション
- 統一状態: idle / thinking / toolRunning / permissionWaiting / compacting / error / completed
- 現在のツール名の要約テキスト（例: `Edit main.swift`, `npm test`）
- 外部ディスプレイ/notch なし Mac ではフローティングバーとして表示
- 詳細は `docs/data-and-display-spec.md` §5.1 参照

#### 4.1.2 展開モード（クリック/ホバーで展開）

- アクティブ全セッションのカード形式リスト
- 各セッションに表示:
  - エージェント名 + モデル名 + 経過時間
  - 現在のツール + 引数要約
  - トークン消費量（in/out。Gemini は total のみ）+ コスト推計
  - ツール実行回数 + 作業ディレクトリ（Claude/Gemini のみ）
- 権限待ちバッジ（件数表示）
- 詳細は `docs/data-and-display-spec.md` §5.2 参照

#### 4.1.3 フルパネルモード（さらにクリックで展開）

- **セッション詳細タブ**: ツール実行履歴（名前+引数+時刻+結果）、Edit 差分プレビュー（Claude のみ）、トークン内訳
- **権限管理タブ**: Approve/Deny 操作（Claude のみ GUI 対応）、Codex/Gemini はターミナルジャンプボタン、承認履歴
- **テレメトリタブ**: 日次コスト集計、エージェント別比率、7日間トレンド、CSV/JSON エクスポート
- 詳細は `docs/data-and-display-spec.md` §5.3 参照

### 4.2 権限管理

| 機能       | 説明                                                       |
| ---------- | ---------------------------------------------------------- |
| 承認/拒否  | ツール実行リクエストを notch から approve/deny（**Claude Code のみ** GUI 操作可能。Codex/Gemini は観測+ターミナルジャンプ） |
| プレビュー | 実行内容の Markdown プレビュー（ファイル差分、コマンド等） |
| 一括承認   | 信頼するツール/パターンの自動承認ルール設定                |
| 履歴       | 過去の承認/拒否アクションのログ                            |

### 4.3 テレメトリ & 分析

| 機能                 | 説明                                                       |
| -------------------- | ---------------------------------------------------------- |
| リアルタイムトークン | input/output トークンをリアルタイム表示                    |
| コスト推計           | モデル別単価に基づく API コスト推計                        |
| セッション統計       | セッションごとの所要時間、ツール呼び出し回数、トークン合計 |
| 日次/週次レポート    | ローカル SQLite に蓄積し、トレンド表示                     |
| エクスポート         | CSV / JSON でのデータエクスポート                          |

### 4.4 通知 & サウンド

| イベント       | デフォルト演出                                |
| -------------- | --------------------------------------------- |
| タスク完了     | notch フラッシュ + サウンド                   |
| 権限リクエスト | notch パルスアニメーション + アラートサウンド |
| エラー発生     | 赤フラッシュ + エラーサウンド                 |
| 長時間アイドル | フェードアウト通知                            |

- サウンドはカスタマイズ可能（ユーザー指定 .wav/.mp3 対応）
- macOS 通知センター連携（バックグラウンド時）

### 4.5 ターミナルジャンプ

| 機能                 | 説明                                                           |
| -------------------- | -------------------------------------------------------------- |
| 対応ターミナル       | iTerm2, Terminal.app, Ghostty, Warp, Alacritty, Kitty, WezTerm |
| セッション特定       | PID + pty でエージェント実行中のペインを正確に特定             |
| ワンクリックジャンプ | notch から該当ターミナルペインに直接フォーカス                 |
| tmux/split pane      | tmux セッション・ウィンドウ・ペインレベルの特定                |

### 4.6 プラグインシステム

```
~/.agent-notch/plugins/
├── my-custom-agent/
│   ├── manifest.json    # メタデータ、対応イベント定義
│   ├── adapter.swift    # or adapter.js — エージェント通信ロジック
│   └── widget.swift     # オプション: カスタム UI ウィジェット
```

- **Adapter Protocol**: エージェントの出力をアプリ内部の統一イベントモデルに変換
- **Widget Protocol**: notch UI に独自のウィジェットを追加
- **設定 UI**: プラグインの有効/無効、設定をアプリ内で管理

## 5. 非機能要件

### 5.1 パフォーマンス

| 指標           | 目標値                                    |
| -------------- | ----------------------------------------- |
| メモリ使用量   | < 40MB（アイドル時）                      |
| CPU 使用率     | < 1%（アイドル時）、< 5%（アクティブ時）  |
| 起動時間       | < 1秒                                     |
| イベント遅延   | < 100ms（エージェントイベント → UI 反映） |
| バッテリー影響 | 最小限（Energy Impact: Low 維持）         |

### 5.2 プライバシー & セキュリティ

- **完全ローカル動作**: 外部サーバーへのデータ送信なし
- **テレメトリなし**: 匿名利用統計の送信も一切なし（Claude Island との差別化）
- **コード/会話内容の保存**: ローカル SQLite、暗号化オプション
- **アクセシビリティ権限**: 必要最小限の説明と理由表示

### 5.3 互換性

| 項目             | 要件                           |
| ---------------- | ------------------------------ |
| macOS バージョン | macOS 14 (Sonoma) 以降         |
| ハードウェア     | Apple Silicon + Intel 対応     |
| notch なし Mac   | フローティングバーモードで動作 |
| 外部ディスプレイ | 任意のディスプレイに表示可能   |

## 6. ユーザーストーリー

### 開発者 A: マルチエージェント並列開発

> Claude Code と Codex を同時に走らせて、notch で両方の進捗を監視。
> Claude Code が権限を求めたら notch からワンタップで承認。
> Codex が完了したらサウンドで通知を受け、ターミナルにジャンプしてレビュー。

### 開発者 B: コスト意識の高いチームリード

> 日次のトークン消費レポートをチェック。
> 特定のモデル/エージェントのコスト比率を確認し、チームのAI利用を最適化。

### 開発者 C: カスタム環境

> 社内独自の AI ツールをプラグインで Agent Notch に統合。
> カスタムテーマでチームカラーに統一した UI を構築。

## 7. 技術要件サマリー

### 内部アーキテクチャ（概要）

```
┌─────────────────────────────────────────┐
│              Agent Notch App            │
├─────────────────────────────────────────┤
│  Notch UI Layer (SwiftUI + animations) │
├─────────────────────────────────────────┤
│  Unified Event Bus                      │
│  ┌──────────┐ ┌──────────┐ ┌─────────┐ │
│  │ Claude   │ │ Codex    │ │ Plugin  │ │
│  │ Adapter  │ │ Adapter  │ │ Adapter │ │
│  └────┬─────┘ └────┬─────┘ └────┬────┘ │
│       │            │            │       │
│  Hooks/Socket  OTLP/HTTP   Protocol    │
├─────────────────────────────────────────┤
│  Persistence (SQLite)                   │
│  Analytics Engine                       │
│  Plugin Manager                         │
└─────────────────────────────────────────┘
```

### 主要な技術的制約

- **Swift 必須**: macOS ネイティブ notch 操作には AppKit/SwiftUI が必要
- **OTLP 実装**: Codex 統合に HTTP サーバー機能が必要（port 4318）
- **Unix socket**: Claude Code hooks との通信
- **Accessibility API**: ターミナルジャンプに macOS アクセシビリティ権限が必要
- **ログイン項目**: 自動起動対応

## 8. スコープ外（意図的に除外）

| 除外項目                           | 理由                                 |
| ---------------------------------- | ------------------------------------ |
| エージェントのオーケストレーション | Conductor が解決済。監視に集中       |
| エージェントへのプロンプト送信     | ターミナルジャンプで代替。複雑性回避 |
| クラウド同期                       | プライバシーファースト。ローカル完結 |
| Windows/Linux 対応                 | macOS notch 体験に集中。将来検討     |
| 有料機能                           | 完全無料 OSS。スポンサーシップで持続 |
